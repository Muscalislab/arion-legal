Usage des données

Ces données servent uniquement à synchroniser mon planning de travail avec mon agenda personnel. Elles ne servent à aucun profilage, à aucune publicité et ne sont jamais revendues.

L’outil demande uniquement la portée calendar.events. Il n’accède à aucun autre contenu du compte Google.

L’usage des informations reçues des API Google respecte la politique d’utilisation des données des services API de Google (Google API Services User Data Policy, en anglais), y compris les exigences d’utilisation limitée (Limited Use).
